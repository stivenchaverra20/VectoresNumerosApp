#  Vector Numeros App (Java)

##  Descripción
Programa académico que crea un vector de 15 números enteros, valida el rango (10-100), permite buscar un valor, determina el mayor y menor, identifica múltiplos, calcula la suma total y genera un nuevo vector con los valores por encima del promedio.

##  Requisitos
- Java JDK 11 o superior (Eclipse Temurin)
- VS Code con la extensión `Extension Pack for Java` instalada

##  Cómo ejecutar
1. Abre la carpeta del proyecto en VS Code
2. Abre la terminal integrada (`Ctrl + \``)
3. Compila: `javac VectorNumerosApp.java`
4. Ejecuta: `java VectorNumerosApp`
